# Finars Studio Space 3.0

Modern redesign of the **FIN ARS d.o.o.** architecture studio website.

## Features

- Clean, sophisticated design inspired by Apple and contemporary architecture firms
- Fully responsive (mobile + desktop)
- Animated hero background with subtle zoom
- Project gallery with lightbox image zoom
- Individual project pages with original images from finars.si
- Pages: Home, Projects, About, Contact

## Live structure

- `index.html` – Homepage
- `projekti.html` – Projects overview
- `o-nas.html` – About the studio
- `kontakt.html` – Contact details
- `projekti/` – Individual project detail pages

## Original studio

[www.finars.si](https://www.finars.si) – FIN ARS d.o.o., Zagorje ob Savi, Slovenia
